# TokenBar Decision Log

This file records each product and technical decision. Each row has a date, the decision, the reason and the documents that the decision changed.

**Rules.**

1. Add a new row for each new decision. Do not delete a row.
2. If a decision replaces an older decision, add a new row. Write "Replaces D<n>" in the reason.
3. Write each row in ASD-STE100 (AGENTS.md Section 2).
4. The requirement documents hold the detail. This log holds the summary and the reason.
